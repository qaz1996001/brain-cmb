# RFC 2119 合規性檢查清單 (Compliance Checklist)

**文件 ID**: REG-RFC2119-002  
**標題**: 需求關鍵字合規性檢查清單  

---

## 需求撰寫檢查項

| 檢查項 | 狀態 | 備註 |
|-------|------|------|
| 是否所有強制性需求都使用了 **MUST** 或 **SHALL**？ | [ ] | |
| 是否所有推薦但非強制的行為都使用了 **SHOULD**？ | [ ] | |
| 是否所有選配功能都標註為 **MAY**？ | [ ] | |
| 關鍵字是否使用了**全大寫**格式？ | [ ] | |
| 單個需求句中是否避免了多個關鍵字導致的歧義？ | [ ] | |
| 所有的 **MUST** 需求是否在追溯矩陣中都有對應的測試案例？ | [ ] | |

---

## AI 審核規則 (For AI Agents)

在進行變更提案 (OpenSpec Proposal) 時，AI 應自動掃描 spec deltas 並驗證以下內容：

1. **語法校驗**：檢查是否誤用了小寫的 must, should, may。
2. **優先級校驗**：如果提案中包含了大量 MUST，應評估是否所有項目都是 Phase 1 必備。
3. **一致性校驗**：確保新加入的需求描述風格與現有文檔一致。
