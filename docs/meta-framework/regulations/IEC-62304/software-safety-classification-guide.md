## 1. 軟體安全分類概述

IEC 62304 依據軟體可能造成的傷害程度，將軟體分為三個安全等級：

- **Class A**: 無法造成傷害
- **Class B**: 可能造成傷害但不嚴重
- **Class C**: 可能造成死亡或嚴重傷害

## 2. 分類標準

### 2.1 Class A

軟體無法造成傷害的情況：
- 軟體不直接控制醫療器材功能
- 軟體僅用於資料記錄或顯示
- 軟體故障不會影響醫療器材安全功能

### 2.2 Class B

軟體可能造成傷害但不嚴重：
- 軟體控制非關鍵醫療功能
- 軟體故障可能導致不適但不會造成嚴重傷害
- 軟體有備援機制

### 2.3 Class C

軟體可能造成死亡或嚴重傷害：
- 軟體控制關鍵醫療功能
- 軟體故障可能導致死亡或嚴重傷害
- 軟體無備援機制或備援不足

## 3. 分類流程

1. **識別軟體功能**
2. **評估潛在危害**
3. **評估傷害嚴重程度**
4. **確定安全分類**
5. **記錄分類決策**

## 4. 分類影響

不同安全分類對應不同的文檔與流程要求：

| 要求 | Class A | Class B | Class C |
|------|---------|---------|---------|
| 軟體需求規格 | 必需 | 必需 | 必需 |
| 軟體架構設計 | 必需 | 必需 | 必需 |
| 軟體詳細設計 | 建議 | 必需 | 必需 |
| 軟體單元測試 | 建議 | 必需 | 必需 |
| 軟體整合測試 | 建議 | 必需 | 必需 |
| 軟體系統測試 | 建議 | 必需 | 必需 |
| 軟體風險管理 | 建議 | 必需 | 必需 |
