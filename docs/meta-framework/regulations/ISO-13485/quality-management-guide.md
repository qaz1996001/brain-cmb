## 1. 概述

ISO 13485:2016 規範醫療器材品質管理系統的要求，確保醫療器材在整個生命週期內符合法規要求與客戶需求。

## 2. 品質管理系統建立

### 2.1 品質管理系統範圍

定義品質管理系統的適用範圍，包括：
- 產品範圍
- 組織範圍
- 地理範圍

### 2.2 品質政策與目標

- 品質政策：組織對品質的承諾
- 品質目標：可量測的品質目標

## 3. 文檔要求

### 3.1 品質手冊

建立品質手冊，描述品質管理系統的結構與流程。

### 3.2 程序文件

建立必要的程序文件，包括：
- 文檔控制程序
- 設計與開發程序
- 採購程序
- 生產程序
- 量測與監控程序

## 4. 設計與開發

### 4.1 設計與開發規劃

- 設計階段劃分
- 設計審查點
- 設計驗證與確認活動

### 4.2 設計輸入

- 功能需求
- 性能需求
- 法規要求
- 風險管理要求

### 4.3 設計輸出

- 設計規格
- 測試規格
- 使用者文檔

## 5. 風險管理整合

ISO 13485 要求整合 ISO 14971 風險管理流程：
- 風險管理計劃
- 風險分析
- 風險控制措施
- 風險監控

## 6. 持續改進

- 內部稽核
- 管理審查

- 持續改進活動
