## 1. 風險管理流程概述

ISO 14971 定義的風險管理流程包括：
1. 風險分析
2. 風險評估
3. 風險控制
4. 剩餘風險評估
5. 風險管理審查

## 2. 風險分析

- 危害識別
- 危害情境識別
- 風險估計

## 3. 風險評估

- 風險可接受性判斷
- 風險等級劃分

## 4. 風險控制

- 風險控制措施選擇
- 風險控制措施實施
- 風險控制措施驗證
