# Spec Delta: meta-framework-regulations

## ADDED Requirements

### RFC-2119-REG-001: Requirement Keywords Support
The meta-framework SHALL provide a standardized guide for using RFC 2119 keywords (MUST, SHALL, SHOULD, MAY, etc.) in requirement documentation.

### RFC-2119-REG-002: Compliance Checklist
The meta-framework SHALL provide a checklist to verify that requirements follow RFC 2119 conventions.

## MODIFIED Requirements

### REG-META-001: Regulations Index
The index SHALL include RFC 2119 as a core regulation for requirement specification quality.
